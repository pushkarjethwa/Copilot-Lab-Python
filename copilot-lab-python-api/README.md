# Copilot Lab Python API

A Python API project for learning and experimenting with GitHub Copilot.

## Project Structure

```
copilot-lab-python-api/
  README.md
  requirements.txt
  app/
    main.py
    models.py
    services.py
  tests/
    test_main.py
  docs/
    api_examples.md
  .github/
    pull_request_template.md
```

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python -m app.main
   ```

3. Run tests:
   ```bash
   pytest tests/
   ```
